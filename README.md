# 湯の里

## 概要
温泉をテーマに制作したWebサイトです。温泉の魅力を伝え、利用者が楽しみながら閲覧できるサイトを目指しました。

## 使用技術
- HTML
- CSS

## 制作目的
職業訓練で学んだWeb制作の知識を活用し、実際にWebサイトを制作することで、HTML・CSSの理解を深めることを目的としました。

## 工夫した点
- 温泉をイメージしたデザインを意識しました。
- 文字や画像の配置を調整し、見やすいレイアウトを目指しました。
- HTMLとCSSを使用して、ページの構成やデザインを作成しました。

## 制作環境
- Visual Studio Code
- HTML
- CSS
